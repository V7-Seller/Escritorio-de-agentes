# Operação N7 · Escritório N7 Ecom

Escritório isométrico estilo Habbo, com visual futurista, da operação de e-commerce N7 Ecom (Mercado Livre, Shopee, Magalu e Amazon).

- **Salas:** Sala do Chefe, Funcionários, Reunião e Jogos. Troque pelas abas no topo ou clicando nas portas neon.
- **Andar:** clique no chão para mover o Daniel.
- **Monitores:** mostram uma réplica animada do mercadolivre.com.br. Clique para ampliar e abrir o site real. O Mercado Livre não permite ser exibido em iframe.
- **Logo:** `logo.svg` (completa) e `logo-mark.svg` (símbolo).

## Rodar

Na pasta `operacao-n7`:

```bash
npx http-server -p 5173
```

Depois abra http://localhost:5173.
